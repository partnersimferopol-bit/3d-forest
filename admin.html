Открыть сайт

На компьютере: «Сохранить на сайте» — только в этом браузере (localStorage). Откройте главную с ?preview=1 и нажмите Ctrl+F5.

GitHub Pages не видит localStorage. Чтобы тексты, отзывы и фото появились на partnersimferopol-bit.github.io/3d-forest/, нажмите «Опубликовать на сайт» → положите скачанный файл в assets/site-content.json, фото — в assets/products/, затем git push (или отправьте файлы разработчику).
